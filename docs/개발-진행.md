# minho2 개발 진행 (핸드오프)

> 새 세션은 이 문서부터 읽고 *이어간다*. 매번 처음부터 다시 묻지 않는다.

## 프로젝트 한 줄
형(신기훈)이 아들 민호와 만드는 **두 번째 게임**. 첫 게임 mino1을 졸업하고 **Godot 엔진으로 한 차원 높여** 새로 시작한다. 목적은 "민호랑 즐겁게"이되, **민호 눈높이가 높아져서 '진짜 게임처럼' 보여야 한다.**

## 결정된 것 (2026-06-20)
- **엔진 = Godot 4.** 이유: 움직이는 그림·물리·파티클·소리가 기본 기능 → "장난감 티" 탈출. 웹(HTML5) export 가능 → 민호는 링크로 폰 플레이 유지. (mino1의 Phaser 웹 2D는 에셋을 손으로 다 깎아야 해서 70점 천장이었음.)
- **목적 = 민호와 즐겁게 (포폴·수입 1순위 아님).** 단 민호 눈높이 높음 = 핵심 조건.
- **방향 3원칙** (mino1 교훈에서 도출): ①재미 한 가지를 먼저 한 문장으로 박기 ②에셋(움직이는 그림·소리)을 1순위로, AI로 일관되게 뽑기 ③적은 에셋으로 깊게 노는 장르를 영리하게 고르기.
- **"수준"의 정체** = 3D가 아니라 애니메이션 + 사운드 + 폴리시(매끈함). (안내판 CLAUDE.md에 상세.)

## 아직 안 정한 것 (병목 — 형 결정 필요)

2. **민호가 평소 자주 하는 게임** — 민호 눈높이의 실제 기준. 형에게 물어볼 것.

## 환경·배포 (2026-06-20 구축)
- **Godot 4.3** = `~/godot/Godot_v4.3-stable_linux.x86_64` (WSL, 헤드리스로 import·export 가능). export 템플릿도 설치됨.
- **GitHub repo** = `joyhunny/minho2` (public). 소스=`master`, 웹빌드=`gh-pages`.
- **민호 폰 접속 주소** = https://joyhunny.github.io/minho2/
- **재배포 = `bash tools/deploy.sh`** (import→web export→gh-pages push 한 방). single-thread export라 Pages에서 헤더 설정 없이 바로 열림.
- **한글 폰트** = `fonts/Jua-Regular.ttf` (둥근 한글). 라벨에 `_make_label()`로 적용.
