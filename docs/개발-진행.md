# minho2 개발 진행 (핸드오프)

> 새 세션은 이 문서부터 읽고 *이어간다*. 매번 처음부터 다시 묻지 않는다.

## 프로젝트 한 줄
형(신기훈)이 아들 민호와 만드는 **두 번째 게임**. 첫 게임 mino1을 졸업하고 **Godot 엔진으로 한 차원 높여** 새로 시작한다. 목적은 "민호랑 즐겁게"이되, **민호 눈높이가 높아져서 '진짜 게임처럼' 보여야 한다.**

## 결정된 것 (2026-06-20)
- **엔진 = Godot 4.** 이유: 움직이는 그림·물리·파티클·소리가 기본 기능 → "장난감 티" 탈출. 웹(HTML5) export 가능 → 민호는 링크로 폰 플레이 유지. (mino1의 Phaser 웹 2D는 에셋을 손으로 다 깎아야 해서 70점 천장이었음.)
- **목적 = 민호와 즐겁게 (포폴·수입 1순위 아님).** 단 민호 눈높이 높음 = 핵심 조건.
- **방향 3원칙** (mino1 교훈에서 도출): ①재미 한 가지를 먼저 한 문장으로 박기 ②에셋(움직이는 그림·소리)을 1순위로, AI로 일관되게 뽑기 ③적은 에셋으로 깊게 노는 장르를 영리하게 고르기.
- **"수준"의 정체** = 3D가 아니라 애니메이션 + 사운드 + 폴리시(매끈함). (안내판 CLAUDE.md에 상세.)

## 아직 안 정한 것 (병목 — 형 결정 필요)
1. **장르·핵심 재미** — "이 게임은 30초에 한 번 ___하는 맛" 한 문장. (형 미감·민호 취향 필요.)
2. **민호가 평소 자주 하는 게임** — 민호 눈높이의 실제 기준. 형에게 물어볼 것.

## 환경·배포 (2026-06-20 구축)
- **Godot 4.3** = `~/godot/Godot_v4.3-stable_linux.x86_64` (WSL, 헤드리스로 import·export 가능). export 템플릿도 설치됨.
- **GitHub repo** = `joyhunny/minho2` (public). 소스=`master`, 웹빌드=`gh-pages`.
- **민호 폰 접속 주소** = https://joyhunny.github.io/minho2/
- **재배포 = `bash tools/deploy.sh`** (import→web export→gh-pages push 한 방). single-thread export라 Pages에서 헤더 설정 없이 바로 열림.
- **한글 폰트** = `fonts/Jua-Regular.ttf` (둥근 한글). 라벨에 `_make_label()`로 적용.

## S2 산출물 위치 (다음 세션 참고)
- **HUD**: `ui/HUD.gd` (Control + `_draw`). 좌상단 레벨 뱃지·HP/MP/XP 바·직업·킬·골드, 우상단 퀘스트(목표) 텍스트. mino1 `_drawHUD` 대응. 매 프레임 직접 그림(둥근 사각은 `_round_rect` 헬퍼). 숫자는 Label(Jua 폰트)로 위에 얹음. 임시 `info_label` 은 화면 하단 안내/게임오버용으로 강등.
- **레벨업 3택**: `ui/LevelupPanel.gd` (Control). mino1 `_openLvlupPanel`/`_processLevelupQueue`/`_applySkill` 대응. **큐 방식** — 한 번에 여러 레벨이 올라도 `queue_levelup(n)` → `process_queue()` 로 *하나씩* 띄움. 떠 있는 동안 `get_tree().paused=true`(패널은 `PROCESS_MODE_ALWAYS`). 스킬 3개는 **결정론 RNG**(`Main.core_rng()`, 시드=`GameState.seed_val`)로 뽑음. 카드 선택 → `Main.apply_skill(id)`.
- **스탯 분배**: `ui/StatPanel.gd` (Control). mino1 `_drawStatBtn`/`_drawStatPanel`/`_handleStatTap` 대응. 우상단 'STAT' 토글 버튼(포인트 있으면 주황 빛+빨강 뱃지) → 7종 행(공격력·공격속도·방어·최대HP·최대MP·이동속도·경험치획득) + 골드 100→포인트 1 환전. 증가값·클램프(공속 0.12 하한, sp 380, swift 320)·`spentStats` 누적 전부 mino1 보존. 스탯창은 게임을 *멈추지 않음*(mino1 동일).
- **스킬 효과**: `Main.apply_skill()` — sword_mastery(+5 atk)·quick_strike(쿨×0.8)·iron_wall(+3 armor)·swift_wind(+22 sp,≤320)·wide_slash(+14 range)·vitality(+20 maxhp 즉회복). critical·life_drain 은 패시브 → `Main._update_combat` 명중 루프에서 매번 읽음(life_drain +1.5×스택 회복, 치명타+quick_strike 시 다음 쿨 ×0.7).
- **자동회복**: `Main._update_regen` (S1 부터 있음, S2 에서 그대로) — 1초마다 난이도 regen 만큼 HP, MP +2.
- **레이어 순서**(CanvasLayer): HUD=5, info=6, StatPanel=8, LevelupPanel=10(ALWAYS). 조이스틱/공격버튼은 기존 레이어.
- **검증**: import 0에러 · 성장 통합테스트(레벨업 큐 5렙·스킬 4종 큐 소진·일시정지 복귀·7종 분배·골드 환전·전 스탯 분기·regen 회복) ALL OK · 실전 전투 1200프레임(자연 레벨업+패널 자동선택+스탯창 동시) 크래시 0.
