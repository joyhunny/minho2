# mino1 → minho2(Godot) 포팅 설계도 (SSOT)

> 이 문서가 포팅의 **단일 기준(SSOT)**이다. 새 세션은 여기부터 읽고 이어간다.
> 형 결정(2026-06-20): **mino1 전체를 Godot로 옮긴다.** 단 "그대로 베끼기"가 아니라 **옮기는 과정에서 Godot 강점(애니메이션·소리·이펙트·물리)을 입혀 한 단계 올린다.**

## 0. 핵심 원칙
1. **전체 포팅, 단, 단계(슬라이스)로 나눠서.** 8천 줄을 한 번에 못 옮긴다 → 굴러가는 조각을 하나씩 쌓고, 매 조각마다 검증·배포한다.
2. **옮기며 업그레이드.** mino1의 약점이던 "정지 이미지·무음"을 Godot에서 메운다: 캐릭터 찌그러짐/넉백/히트스톱은 Godot Tween·물리로, 타격음·BGM은 AudioStreamPlayer로.
3. **데이터는 1:1, 렌더는 재설계.** `core.js`(상수·공식)는 GDScript로 거의 그대로. `play.js`(Phaser 렌더)는 Godot 노드 트리로 다시 짓는다.
4. **밸런스 숫자는 mino1 값을 정본으로 보존.** (적 HP·데미지·XP·난이도 배율·드랍률 등 — 이미 민호로 검증된 값.)

## 1. mino1 구조 요약 (무엇을 옮기나)

### 데이터 (`core.js` 254줄 — 거의 1:1 이식)
- `WORLD` 2200×2200, 결정론 RNG, `clamp`
- `freshPlayer()` — 플레이어 기본 스탯(hp·mp·atkPow·sp·lvl·xp·equip·job·statPoints·gold…)
- `ENEMY_DEFS` 9종(slime·rat·pig·crow·toad·hedgehog·boar·croc·wolf): hp·속도·dmg·xp·sprite·minLvl
- `REGION_DEFS` 4지역(들판·늪·폐허·성): 적 풀·보스·바위/독/버프 수·이동배율·엘리트율·색
- `SKILL_DEFS` 8(레벨업 3택 스킬), `RARITY_TABLE` 5등급, `ITEM_DEFS` 약 50종(무기·방어구·악세, 전직전용 noDrop 포함)
- `DIFFICULTY_DEFS` 10단계(쉬움→임파서블 신: dmgMult·hpMult·regen), `GOLD_DROP`/`GOLD_SELL_PRICE`
- 함수: `pickEnemyType`·`rollRarity`·`tryDrop`

### 시스템 (`play.js` 7661줄 — Godot 노드로 재구성)
- **화면 흐름**: 인트로 → 난이도 선택 → 전투 → 월드맵 → 지역 입장 → 챕터 스토리 → 게임오버/이어하기
- **맵·지형**: 풀밭, 지형 존(독장판·바위 장애물·버프 크리스탈) + 지형 효과
- **플레이어**: 이동(조이스틱+키), 근접 공격 스윙, 무적, 피격, 의사 애니
- **동료**: 카피바라 동료(따라오기·힐), 소환 아군 슬라임
- **적**: 스폰·엘리트, AI(추격·공격), 애니, 그림자, 독침 투사체
- **전투**: 근접 판정, 데미지, 히트스톱, 럼지(돌진), 데미지 숫자, 파티클·임팩트
- **성장**: 경험치/레벨업(3택 스킬), 스탯 7종 분배(+골드 환전), 전직 1차(전사·마법사·도적)·2차(마검사·대마법사·닌자)
- **스킬**: 기본(파이어볼·메테오·순간이동·무적·워터폴·소환) + 전직 클래스 스킬 12종, 쿨다운·마나
- **장비**: 인벤토리·줍기·장착/해제·판매(골드)·5등급 드랍
- **보스**: 4종(멧돼지왕·악어·늑대왕·코끼리) 패턴·예고·HP바·메테오·보스 등장 연출
- **요리**: 고기 드랍·그릴·회복
- **UI/HUD**: HP/MP/XP바·골드·퀘스트·공격버튼·조이스틱·스킬 트레이·인벤·스탯 버튼
- **이펙트/연출**: 파티클·임팩트·플래시·히트스톱·노바·슬래시·카메라 흔들림·mino 시그니처
- **이스터에그**: 좌상단 +10레벨, 좌하단 12연타 +12레벨
- **저장/복원**: localStorage(자동 저장) → Godot는 user:// 저장 파일로

## 2. Godot 프로젝트 구조 (목표 모습)
```
minho2/
  project.godot            # 모바일 세로, gl_compatibility
  autoload/
    GameData.gd            # core.js 데이터 전부 (상수 Dictionary) — autoload 싱글톤
    GameState.gd           # 플레이어 상태 + 저장/복원 (user://save.json)
  scenes/
    Main.tscn / Main.gd    # 메인 게임 루프, 맵, 카메라
    Player.tscn / Player.gd
    Enemy.tscn / Enemy.gd
    Boss.tscn / Boss.gd
    Companion.tscn
  systems/                 # 순수 로직 (노드 아님)
    Combat.gd  Spawner.gd  Terrain.gd  Skills.gd  Inventory.gd  Loot.gd
  ui/
    HUD.gd  IntroPanel  DifficultyPanel  LevelupPanel  JobPanel
    StatPanel  InventoryPanel  WorldMapPanel  SkillTray
  assets/
    sprites/   # mino1 캐릭터·적 이미지 가져옴 (추후 동작 그림 추가)
    fonts/     # Jua (한글)
    sfx/  bgm/ # ★ 새로 추가 (mino1엔 거의 없던 것)
```
**Godot 강점 적용 지점:** 적/플레이어 = 노드(Area2D/CharacterBody2D)+충돌 / 애니 = Tween·AnimationPlayer / 파티클 = GPUParticles2D / 소리 = AudioStreamPlayer / 흔들림·플래시 = Camera2D+CanvasLayer.

## 3. 시스템 매핑 (mino1 → Godot)
- Phaser `Scene.create/update` → Godot `Main._ready/_process`
- Phaser `physics group`(적) → 적 노드들 + Area2D 충돌
- 수동 거리 충돌 판정 → Godot Area2D `area_entered`(또는 유지 — 성능 보고 선택)
- `this.gs`(게임상태 객체) → `GameState` autoload 싱글톤
- `window.MinoCore.*` 상수 → `GameData` autoload
- localStorage 저장 → `FileAccess` user://save.json
- Phaser `Graphics`(HUD·이펙트 직접 그리기) → Godot `Control`/`Node2D _draw()` 또는 노드 구성
- Phaser `Text` → Godot `Label`(Jua 폰트)

## 4. 슬라이스(단계) 계획 — 각 단계 끝에 검증·배포
- **S0 — 기반 뼈대**: 프로젝트 구조 + `GameData`(core.js 데이터 전부 이식) + `GameState` + 맵(2200²·카메라·풀밭) + 플레이어 이동(조이스틱/키). → *빈 맵에서 주인공이 움직인다.*
- **S1 — 전투 코어 + 손맛** ★게이머 1순위: 적 스폰·추격 AI·근접 공격·데미지·사망·경험치 + **Godot 손맛(넉백·히트스톱·파티클·타격음·카메라 흔들림)**. → *적을 때리는 맛이 산다.*
- **S2 — 성장**: 레벨업 3택 스킬 + 스탯 7종 분배 + HUD(HP/MP/XP·골드).
- **S3 — 전직 + 스킬**: 1·2차 전직 + 스킬 메뉴 + 캐스팅(쿨·마나).
- **S4 — 장비·요리·골드**: 인벤토리·드랍·장착·판매·요리.
- **S5 — 지역 + 보스**: 월드맵·4지역 규칙·보스 4종 패턴·난이도 선택.
- **S6 — 연출·사운드 마감**: 인트로·챕터 스토리·동료·mino 시그니처 + BGM/효과음 통합·폴리시.

## 5. 검증·배포
- **검증**: 매 슬라이스 끝 — ① Godot 헤드리스 import/실행으로 에러 0 확인 ② playwright(윈도우 node+크로미움)로 배포본 화면 스샷 → 조이봇이 직접 확인 ③ 형/민호 실기기.
- **배포**: `bash tools/deploy.sh` → https://joyhunny.github.io/minho2/ (민호가 진행 상황을 폰에서 본다).

## 6. 에셋 처리
- mino1 캐릭터·적 이미지(`~/play/mino1/game/sprites`, `assets`) → minho2 `assets/sprites`로 가져온다(같은 그림 재사용).
- **사운드는 새로**(mino1엔 거의 없음) — 무료 효과음/BGM(CC0) 또는 생성.
- **캐릭터 동작 그림**(공격·피격 포즈)은 별도 트랙(형 AI 생성, `에셋-캐릭터-동작-가이드.md`) — S1 손맛 단계에서 있으면 입히고, 없으면 Godot Tween 의사 애니로 먼저.
